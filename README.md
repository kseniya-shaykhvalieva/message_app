# Сервис управления рассылками

Веб-приложение на Django для управления рассылками сообщений, клиентами, а также сбора статистики и разграничения прав доступа.

## Основной функционал

- Управление клиентами (получателями): создание, просмотр, редактирование, удаление.
- Управление сообщениями: создание, просмотр, редактирование, удаление.
- Управление рассылками: создание, просмотр, редактирование, удаление, ручной запуск отправки.
- Автоматическое обновление статуса рассылки (`Создана`, `Запущена`, `Завершена`).
- Отправка писем с записью попыток (`успешно`/`не успешно`, ответ сервера).
- Статистика по рассылкам пользователя (успешные/неуспешные попытки, количество отправленных сообщений).
- Регистрация с подтверждением email и восстановлением пароля.
- Разграничение прав (обычный пользователь и менеджер с правами блокировки пользователей и отключения рассылок).
- Серверное кеширование страниц (Redis).

## Установка и запуск

1. **Клонирование и переход в директорию**

2. **Установка зависимостей (Poetry):**
```
poetry install
```

3. **Настройка переменных окружения:**
- Скопируйте `.env.sample` в `.env`
- Заполните параметры базы данных, почты, Redis (при необходимости)

4. **Применение миграций и создание суперпользователя:**
```
python manage.py migrate
python manage.py csu # кастомная команда для создания суперпользователя
```

5. **Запуск сервера:**
```
python manage.py runserver
```

## Функциональности

### Пользователи и права

- Регистрация с подтверждением email и восстановлением пароля.
- Обычный пользователь:
- Управляет только своими клиентами, сообщениями и рассылками.
- Просматривает статистику по своим рассылкам.
- Менеджер (группа с правами `can_block_user` и `can_deactivate_mailing`):
- Просматривает всех клиентов и все рассылки.
- Просматривает список пользователей и может их блокировать (`/users/user_list/`).
- Отключает рассылки (кнопка `Отключить/Включить` на странице рассылки).

### Клиенты (получатели)

- Создание (`/mailing_service/recipients/create/`), просмотр, редактирование, удаление.
- Поля: email, ФИО, комментарий.

### Сообщения

- Создание (`/mailing_service/messages/create/`), просмотр, редактирование, удаление.
- Поля: тема письма, тело письма.

### Рассылки

- Создание (`/mailing_service/mailing/create/`) с выбором сообщения и получателей.
- Просмотр, редактирование, удаление, ручной запуск отправки (кнопка `Отправить` на детальной странице).
- Автоматическое обновление статуса при открытии детальной страницы (метод `update_status()`).
- Валидация дат: `start_time` не в прошлом и раньше `end_time`.

### Отправка и попытки

- Функция `send_mailing()` в `services.py`:
- Проверяет, активна ли рассылка (`is_active`), и находится ли текущее время в интервале `[start_time, end_time]`.
- Для каждого получателя отправляет письмо через `send_mail` и создаёт запись `MailingAttempt` со статусом и ответом сервера.

### Статистика

- Страница `/mailing_service/statistics/`:
- Количество успешных и неуспешных попыток рассылок текущего пользователя.
- Количество отправленных сообщений.

### Кеширование

- Серверное кеширование страниц (15 минут) с использованием Redis:
- `ListView` и `DetailView` всех моделей (получатели, сообщения, рассылки) обёрнуты декоратором `@method_decorator(cache_page(60*15), name='dispatch')`.
